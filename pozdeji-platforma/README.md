# Odložené na později: „velká“ platforma

Tady je odložená ukázková administrace pro eventovou agenturu: více klientů, dashboard, účastníci, e-mailové kampaně, zakládání akcí a průvodce demem.

**Jednoduchá verze ji nepotřebuje.** Pro akci v Dukovanech stačí složka `web/`, Google Sheet a Apps Script (viz `NAVOD.md`).

Postup, až budete chtít platformu oživit:
1. Zkopírujte soubory z `pozdeji-platforma/web/` zpět do `web/` (do stejných podsložek).
2. Otevřete `admin.html`. Funguje jen v demo režimu nad fiktivními daty.
